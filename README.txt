MATCHQIP WEBSITE — DEPLOYMENT NOTES

Files:
- index.html: homepage
- assets/styles.css: responsive styling
- assets/main.js: mobile navigation and current year
- assets/favicon.svg: browser icon
- robots.txt and sitemap.xml: basic search-engine discovery

DEPLOY:
1. Download and extract matchqip-website.zip.
2. Open your GitHub repository: https://github.com/AlkabalCharlie/AlkabalCharlie.github.io
3. Choose Add file > Upload files.
4. Upload index.html, robots.txt, sitemap.xml, and the assets folder with its contents.
5. Do NOT delete the existing CNAME file. It must continue to contain exactly: matchqip.com
6. Commit changes to the main branch.
7. Wait for GitHub Pages deployment, then test https://matchqip.com.

IMPORTANT:
- The website links to the current Microsoft Store listing and existing privacy policy.
- Contact email is mailto:support@matchqip.com. This only works as a useful contact route once that mailbox or email forwarding is configured. Change it if you choose another public support address.
